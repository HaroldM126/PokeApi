# Pokédex App

Aplicación React + Vite que consume [PokéAPI](https://pokeapi.co/) y muestra los primeros 20 Pokémon con búsqueda local.

## Desarrollo

```bash
npm install
npm run dev
```

La URL de la API se configura en `.env` mediante `VITE_POKEAPI_URL`.

## Validación

```bash
npm run lint
npm run build
```
